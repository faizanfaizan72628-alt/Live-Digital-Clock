# 🕐 Digital Clock
A simple and responsive Digital Clock built using HTML, CSS, and JavaScript.
## 🚀 Features
- Live digital clock
- Hours, minutes, and seconds
- AM/PM format
- Current date
- Responsive design
- Simple modern UI
## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
## 📂 Project Structure
digital-clock/
│
├── index.html
├── style.css
├── script.js
└── README.md
## ▶️ How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. The Digital Clock will appear in your browser.
